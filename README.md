# classflow
ClassFlow — Smart Classroom Notification System

ClassFlow is a smart classroom communication system designed to keep students updated about changes in their class schedule and classroom status in real time.

How It Works

The system provides timely notifications to students for important classroom updates:
	•	🔔 Teacher Arrival Notification — Students are notified when a teacher leaves the staff room and is on the way to take their scheduled class.
	•	❌ Class Cancellation — If a teacher cancels a class, students receive an immediate notification so they don’t have to wait unnecessarily.
	•	⏱️ Class Delay Notification — Students are informed when a teacher is delayed or the class is going to start later than scheduled.
	•	🔄 Classroom Change — If the class is shifted to another classroom, students receive an updated notification with the new room number.
	•	📢 Real-Time Updates — All important changes are communicated through a centralized notification system, reducing confusion and unnecessary waiting.

Problem It Solves

Students often wait outside classrooms without knowing whether a teacher is coming, whether a class has been cancelled, or whether the class has been moved to another room. ClassFlow aims to solve this communication gap by providing quick, accurate, and timely classroom updates.

Goal

The goal of ClassFlow is to make everyday college classroom communication smarter, faster, and more convenient for both students and teachers.
